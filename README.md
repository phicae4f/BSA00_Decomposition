# BSA 00: Декомпозиция и сбор информации

## Описание проекта
Вводный проект по направлению «Бизнес и системный-анализ». В рамках работы освоены базовые инструменты аналитика: сбор и каталогизация информации, ведение терминологии, а также применение методов декомпозиции.

Для практики использовались две бизнес-задачи: система онлайн-записи для сети барбершопов и сервис доставки заказов.


## Выполненные задачи

### 1. Каталогизация источников информации
Проведен анализ предметной области для обеих задач. Сформирован каталог источников (статьи, обзоры, нормативные документы). Для каждого элемента определены параметры: надежность, тип и приоритет изучения.
**Артефакт:** `ex01_<префикс>_infosources.xlsx`

### 2. Создание глоссария
Сформирован единый словарь терминов для исключения неоднозначных трактовок. В глоссарий внесены как предметные термины из условий задач, так и методологические понятия.
**Артефакт:** `ex02_<префикс>_glossary.xlsx`

### 3. Декомпозиция систем
Отработаны правила разбиения систем на составные части (подчиненность, единственность критерия, целостность). Выполнены следующие упражнения:
* Анализ демографической пирамиды РФ (определение уровней и критериев разбиения).
* Поиск и исправление ошибок в предложенной декомпозиции завтрака.
* Построение объектной и функциональной декомпозиции для процессов доставки (действия курьеров, роли).
* Разработка событийной декомпозиции активностей дня на основе двух различных целей.


## Стек и инструменты
* **MS Excel** (таблицы, каталоги)
* **MS Word / Draw.io** (визуализация схем)
